# DevDossier 🚀

> **Transform your GitHub activity into a polished, professional developer dossier.**

DevDossier automatically analyzes a developer's GitHub profile, repositories, and activity to generate a structured, visually appealing portfolio/resume overview. Designed with smooth integration for modern workflows and instant AI-driven profile generation.

---

## ✨ Features

- **Automated Profile Analysis:** Fetch public repos, activity logs, and tech stack metrics seamlessly.
- **AI Portfolio Generation:** Turn raw code metrics into readable, impactful summaries and dossier insights.
- **Freemium & Pro Tiers:** Integrated quota management and seamless upgrade flows.
- **Secure Payments:** Instant checkout integration with Razorpay for global/domestic Pro upgrades.
- **Built for Speed & SEO:** High-performance web architecture optimized for fast indexing and discoverability.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS (Built on Lovable)
- **Backend & Database:** Supabase (Auth, Postgres DB, Storage, Edge Functions)
- **Runtime Environment:** Deno (Supabase Edge Runtime)
- **Payment Gateway:** Razorpay SDK
- **Deployment:** Lovable Platform / Vercel

---
